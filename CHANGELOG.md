# Changelog

All notable changes to ERMA are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and ERMA follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-20

### Added
- Initial public release of ERMA.
- Automated quality control of input sequencing data.
- Database preparation for taxonomic and functional reference databases.
- Dual similarity searches against taxonomic and functional databases.
- Integration and filtering of similarity search results.
- Generation of abundance and quality-control summaries.
- Support for Illumina and Oxford Nanopore sequencing data.
- Modular integration of UniRef queries.

### Fixed
- Indication for ONT Test data in README.md

### Changed
- Changeg color of attrition plot bar (filtered fusion reads) to a lighter blue for visibility
